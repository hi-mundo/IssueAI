# Source policy

Use sources in this order: accepted product decisions/specifications; contracts,
schemas and accepted stories; user-visible documentation; stable sibling
behavior and tests; implementation and history; reviewer inference. Official
standards/specifications outrank secondary articles. Repositories are useful
for reproduction only. Preprints and experimental sources are discovery inputs
and must be labeled as such. Every external reference records source, type,
authority, and domain; references do not contain execution instructions.
