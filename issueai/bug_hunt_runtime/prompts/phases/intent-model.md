# Intent model phase

For each prioritized feature, reconstruct expected product and implementation
intent from the highest-authority available sources. Return only the
intent-model schema. Include organization patterns, naming patterns, logical
decisions, typing contracts, and maintainability invariants. Include open
questions for ambiguity or conflict; do not resolve policy by inference from
one anomalous file. The product-understanding artifact is mandatory context:
bind the feature to its product capability, technology stack, architecture,
repository surface and relevant implementation tendencies.

Variable context follows this instruction and contains only the review contract,
feature, and relevant intent evidence.
